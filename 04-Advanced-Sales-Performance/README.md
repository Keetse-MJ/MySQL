# Advanced Sales Performance

## About the Project

This is a MySQL project focused on analysing salesperson performance, sales trends and monthly sales.

## Tools Used

* MySQL
* SQL

## SQL Concepts Used

* Window Functions
* RANK()
* DENSE_RANK()
* LAG()
* LEAD()
* CTEs
* Aggregate Functions
* PARTITION BY

## Dataset

The dataset contains sales information including:

* Salesperson
* Region
* Product
* Category
* Quantity
* Amount
* Sale Date

## Project Files

* `sales_performance_project.sql` - Database and sample data
* `01_salesperson_performance.sql` - Salesperson performance analysis
* `02_sales_trends_analysis.sql` - Sales trends analysis
* `03_advanced_sales_analysis.sql` - Advanced sales analysis

## What I Learned

I practised using SQL window functions and CTEs to analyse sales performance, rankings and trends.
