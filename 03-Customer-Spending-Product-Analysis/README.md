# Customer Spending & Product Analysis

## About the Project

This is a MySQL project focused on analysing customer and order data.

The goal of the project was to use SQL to answer business questions about:

* Customer spending
* Customer orders
* Product sales
* Order amounts
* Customer purchasing behaviour

## Tools Used

* MySQL
* SQL

## SQL Concepts Used

* Subqueries
* CTEs
* Window Functions
* Aggregate Functions
* Advanced Filtering
* CASE Statements
* JOINs

## Dataset

The project uses two tables:

### Customers Table

* Customer ID
* Customer Name
* City
* Email

### Orders Table

* Order ID
* Customer ID
* Product
* Category
* Quantity
* Amount
* Order Date

## Project Files

* `customer_order_project.sql` — Database, tables and sample data
* `01_subqueries.sql` — Customer and order analysis using subqueries
* `02_ctes_window_functions.sql` — Analysis using CTEs and window functions

##  What I Practised

* Finding customers with high total spending
* Comparing customer spending with average spending
* Finding the highest-value orders
* Ranking customers by spending
* Comparing current orders with previous orders
* Calculating running totals
* Finding customers with specific order patterns
* Using SQL to answer business questions

Through this project, I improved my ability to:

* Break complex SQL problems into smaller steps
* Use subqueries for more advanced comparisons
* Use CTEs to make complex queries easier to understand
* Use window functions to rank and compare records
* Combine aggregation with advanced filtering
* Translate business questions into SQL queries
