# Retail Sales Analysis

## About the Project
This is a MySQL project where I worked with retail sales data and used SQL to answer different business questions.

## Tools Used
- MySQL
- SQL

## What I Practiced
- SELECT
- WHERE
- LIKE
- DISTINCT
- GROUP BY
- ORDER BY
- HAVING
- LIMIT
- Aggregate functions
- Aliases

## Dataset
The dataset has 20 sales records. It includes:
- Sale ID
- Customer
- City
- Product
- Category
- Quantity
- Amount
- Sale Date

## Project Files
- 01_basic_sales_queries.sql - Basic SQL queries
- 02_sales_summary.sql - Sales summary questions
- 03_business_questions.sql - Business questions
- 04_final_business_questions.sql - Final business questions
- sales_data.sql - Database and sales data

## What I Learned
Through this project, I practiced using SQL to filter, group, sort and summarize sales data and answer business questions.
