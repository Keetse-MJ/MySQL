# Customer & Order Analysis

## About the Project

This is a MySQL project where I worked with customer and order data to analyze customer purchases, spending, orders and products.

## Tools Used

* MySQL
* SQL

## What I Practiced

* INNER JOIN
* LEFT JOIN
* Multiple-table JOINs
* UNION
* CASE statements
* String functions
* GROUP BY
* HAVING
* ORDER BY
* LIMIT
* Aggregate functions
* Business questions

## Dataset

The dataset contains customer and order information.

### Customers Table

The `customers` table includes:

* Customer ID
* Customer Name
* City
* Email

### Orders Table

The `orders` table includes:

* Order ID
* Customer ID
* Product
* Category
* Quantity
* Amount
* Order Date

## Project Files

* `customer_order_data.sql` - Database, tables and sample data
* `01_inner_joins.sql` - INNER JOIN practice
* `02_left_joins.sql` - LEFT JOIN and multiple JOIN practice
* `03_union_case.sql` - UNION and CASE practice
* `04_string_functions.sql` - String function practice
* `05_business_questions.sql` - Final business questions and analysis

## What I Learned

Through this project, I practiced combining customer and order data using SQL JOINs, classifying data with CASE statements, working with text using string functions, and using SQL to answer business questions. I also practiced analyzing customer spending, order counts and purchasing behaviour.
